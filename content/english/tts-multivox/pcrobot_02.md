  The birth of the PC Robot card was required by the technical progress. There was a need for a PC-plug-in speech synthesizer that triggered the external hardware and was located inside the computer. It only had a speaker output jack. The card was designed by Attila Tihanyi (BME TTT). It was launched on the Hungarian market, in the production of NIKOL Kkt in 1994. It was a popular product. The system spoke Hungarian and the user has got several practical example programs too. These were: READ-text file reader, KIMOND-key input pronouncer, KITALAL-counting game, VOXEDIT-speech and sing programmer, EXCEPT-exception dictionary developer. The sample programs C, Pascal, Turbo Pascal and Assembler helped to program the system. It was also possible to program songs within 4 octaves. Teachers were also able to write their own educational programs, especially for elementary school students. It had a 72-page user guide.<br><br>

  Starting in 2026, thanks to Tamás Géczy, a blind programmer (USA), the voice of PC-ROBOT can once again be heard—even on today’s Windows—using NVDA, a free, open-source screen reader. He uploaded the original PC-ROBOT files (from an old original CD) to the Internet Archive (archive.org).<br>
  The files can be found here: <https://archive.org/details/pcrobot-archive>
  His custom plugin for the NVDA screen reader is available as open source here, along with the installable extension: <https://github.com/tgeczy/pcrobot-emulator>
